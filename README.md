# firefly-installer

Firefly Zero system app for installing other apps using [install.fireflyzero.com](https://install.fireflyzero.com/).

## Installation

```bash
ff import sys.installer
```

## License

GPLv3. Any derivations should be under the same license and open source.

While we encourage device hacking and people writing their own apps, including "sudo" apps, we limit the wifi access to the official installer only. We want Firefly Zero to be an offline device (for the sake of privacy of our users) and hence we currently don't want provide any other internet-connected apps or encourage others create such apps.
